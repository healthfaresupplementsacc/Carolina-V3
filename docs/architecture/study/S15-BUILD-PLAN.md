## API contract — `/api/v3/warehouse/*` (envelope `{ data }`, errors `{ error:{code,message} }`)
- `GET overview` → `data:{ products:[Row], kpis:{total_bottles, reserved, available, separated, unplaced, bins_to_restock, pending_requests, drift_products}, attention:[{kind:'out'|'low'|'negative'|'organizar'|'pending'|'drift'|'sem_local', product_id, product, text, action:{type:'repor'|'organizar'|'aprovar'|'ver'|'entrada', request_id?, bin_id?, box_id?}}], veeqo_checked_at, generated_at }`
  - `Row = { product_id, name, nickname, bottle_color, base_sku, skus:[{id,sku,channel,units_per_pack,role:'base'|'member',veeqo_type:'kit'|'variant'|null,confirmed}], shelf_qty, box_qty, unplaced_qty, total, reserved, pending_out, pending_in, available, separated, min_units, days_cover|null, veeqo:{physical,allocated,available}|null, veeqo_match:'ok'|'drift'|'unknown', status:[…], bins:[{id,bin_code,shelf_code,area,qty,min_qty,needs_restock}], boxes:[{id,box_number,area,qty}] }`
  - `total = shelf_qty + box_qty + unplaced_qty`; `reserved = Σ open lines (status not shipped/cancelled) qty×units_per_pack`; `available = total − reserved − pending_out`; `pending_*` from requests status pending; `separated = Σ stock_issues status separated`; `veeqo` = base SKU physical/allocated/available at wh 108841 (kits never summed); `veeqo_match = ok iff veeqo.physical === total`.
- `GET product/:id` → `data:{ product:Row, open_orders:[{order_number,channel,sku,qty,bottles,order_date,status,age_min}], movements:[{id,kind,qty,bin_code,box_number,person,source,note,created_at}] (last 100), issues:[{id,qty,reason,status,order_number,person,note,created_at}], requests:[{id,kind,qty,status,proposed_by,reason,created_at,decided_by,decided_at}], family:{base:{sku,channel}|null, members:[{id,sku,channel,units_per_pack,veeqo_type,veeqo_available,derived_packs}]} }`
- Writes (manage_stock): `POST product/:id/entrada {qty, bin_id?|box_number?, area?, note?}` (no location → unplaced) · `POST product/:id/place {qty, bin_id?|box_id?}` (unplaced → location) · `POST product/:id/move {qty, from:{bin_id?|box_id?}, to:{bin_id?|box_id?}}` · `POST product/:id/adjust {qty(signed≠0), reason!, bin_id?|box_id?}` · `POST product/:id/separate {qty, reason:'label'|'seal'|'other'|'return', bin_id?, order_number?, note?}` (return = no bin deduction) · `POST issues/:id/resolve {action:'restocked'|'relabeled'|'discarded', bin_id?|box_id?}` · `GET requests?status=` · `POST requests {product_id, kind:'take'|'entrada'|'count'|'return_in'|'issue_release'|'adjust', qty, direction:'out'|'in', bin_id?, box_id?, issue_id?, reason?}` · `POST requests/:id/approve {note?}` · `POST requests/:id/reject {note?}` · `GET locations` · `POST locations/bin {bin_code, shelf_code?, area?, product_id?, min_qty?}` · `POST locations/box {box_number, area?, product_id?, qty?}` · `POST locations/bin/:id/deactivate` · `GET family/:productId` · `POST family/:productId/attach {sku, channel, units_per_pack, role}` · `POST family/detach {sku_id}` · `POST family/merge {from_product_id, into_product_id}` (reassigns SKUs only; stock untouched; 2-step in UI).
- Every write returns `data:{ ok:true, product:Row }` (fresh row) so the UI updates in place. All writes audit; all StockService calls carry `source:'warehouse_hub'`, `actor_type:'admin'`, `person_id` = login's person if any, `note` includes login name.
